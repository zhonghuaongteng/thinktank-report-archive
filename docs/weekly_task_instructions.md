# 国际科技智库每周抓取任务说明（2026-07-12 版）

本说明用于 Codex 自动化「国际科技智库每周抓取」，替代旧版任务说明。相对旧版的主要变化：新增中文摘要充实标准与「核心观点待充实」闸门；漫画从四格证据链改为信息图式漫画；周报 PDF 改为杂志版 HTML 经 Edge headless 打印；建议与中国/上海参考只在报告确有内容时呈现，不再强制进入固定卡片。

## 任务正文

在 `C:\Users\WINDOWS\OneDrive\知识库\智库信息爬虫` 执行国际科技智库周频抓取。

1. 先确认当前分支和工作树状态；如有未提交人工改动，停止并报告。执行 `git pull --ff-only`，然后运行 `C:\Users\WINDOWS\AppData\Local\Programs\Python\Python313\python.exe -m unittest discover -s tests`。测试不通过则停止并报告。

2. 测试通过后运行只读来源健康审计，再运行 `powershell -ExecutionPolicy Bypass -File scripts\run_weekly.ps1 -Batch 1 -Limit 30`。

3. 抓取完成后，为本轮新增 P0/P1 归档补写中文题名与结构化中文摘要，标准如下：
   - `核心观点` 是研究卡片的主体，一般 4-8 句，必须依次覆盖：报告对象与背景（一句）；机构的核心判断及其态度立场（支持/反对/警示/乐观/怀疑及力度，这是必备信息，不能只写"报告讨论了X"）；主要论据与证据（数据、案例、方法，2-4 句）；如报告内部存在争论或承认反方观点，补一句。
   - `建议` 只写报告作者明确提出的政策建议或行动含义；报告没有就整栏省略，禁止写"未检出""待补充"等占位语，禁止用主题套话凑数。
   - `中国/上海参考` 只在报告本身、摘要或主题标签存在明确涉华、涉沪内容或可直接操作的参照时才写；不得从泛化主题硬扯涉华关联。
   - 检查当期 `briefs\weekly\<年份>\<日期>_国际科技智库周报_资料索引.md` 中的「核心观点待充实」清单；清单非空时逐条回原文补写后重新渲染，直到该清单显示达标，才能进入后续步骤。

4. 运行 `powershell -ExecutionPolicy Bypass -File scripts\prepare_weekly_comics.ps1 -Date <YYYY-MM-DD>`，为当期 P0/P1 主题生成信息图式漫画提示词。随后对 `comic\weekly-topic-comics-<YYYY-MM-DD>\prompts\*.md` 逐条调用 Codex 内置图片生成能力或 baoyu-image-gen 的 codex-cli provider，输出到同目录 `pages\`，文件名与提示词同名，扩展名用 `.jpg`。漫画要求：
   - 必须是真实 Codex 生成图，不得回退为程序化示意图、SVG、Pillow、ReportLab 图或占位图。
   - 版式为信息图式漫画：顶部不超过 14 字的大标题概括核心判断；单一视觉隐喻场景作主视觉，主题从报告自身内容中生长（机制剖面、数据景观、人物行动、产业现场、地图均可），禁止切成四格连环画；底部或侧边 2-3 个图标化信息模块；配色限米白、深藏青、砖红、金褐四组；全图中文不超过 40 字。
   - 信息模块只画报告真实包含的内容（关键机制、数据要点、影响对象、争议焦点、趋势信号、应对方向中选最有信息量的 2-3 项）；报告没有给出政策建议就不画应对方向模块；只有提示词"需要表达的核心内容"中出现涉华/涉沪条目时才允许出现中国/上海模块，否则突出报告本身的中心结论。
   - 漫画不要求完整复刻报告论证链，重点用科普化、可视化视角呈现文章观点；若报告正文、摘要或图注中有图表、数据曲线、地图、技术架构图、供应链图、照片或其他证据配图线索，应转译为主视觉中的报告页、屏幕、白板、证据卡或背景装置，只有自动化明确提供真实参考图时才纳入原图参考。

5. 图片生成后运行 `powershell -ExecutionPolicy Bypass -File scripts\render_weekly_brief.ps1 -Date <YYYY-MM-DD>` 重建周报。核验要点：
   - 周报开头必须有综合研判层：本周态势、本周必读（3-5 条一句话判断）、议题观点速览。
   - PDF 应为杂志版 HTML 经 headless Edge 打印生成（可用 `THINKTANK_PDF_BROWSER` 指定浏览器路径）；若因浏览器不可用回退为 reportlab 旧版式，需在报告中说明。
   - PDF 主题页必须呈现「核心判断＋主要论据」，使读者不读原报告也能把握机构立场与论证；政策建议、中国/上海参考卡片只在该条目确有真实内容时出现，缺失不是错误，禁止为对齐版面补占位内容。

6. 运行 `powershell -ExecutionPolicy Bypass -File scripts\check_weekly_comics.ps1 -Date <YYYY-MM-DD>`；若核验失败，停止并报告失败项。核验 `briefs\weekly` 下当周 Markdown、HTML、PDF 是否生成，核验 archive、state、知识库索引是否一致。

7. 若产生归档、简报、漫画、索引或状态相关可提交变更，提交并推送到远程分支；不得写入任何凭据或秘密值。
