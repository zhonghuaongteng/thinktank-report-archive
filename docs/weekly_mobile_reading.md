# 周报手机阅读版

依据2026-10-18至19日用户要求，后续重点、简讯、标题和漫画均用普通读者能理解的表达。默认阅读和既有邮件投递使用手机PDF与响应式HTML，桌面版另存；发送对象、次数及质量门不变。已发送周次的改版不自动重发。

## 已验收版式

本期模板为92×164毫米窄竖页，左右边距6毫米，正文12.2点、1.58倍行距，单栏。按390像素屏宽显示时，正文约18.2像素。小标题14点，文章标题16点，来源10点。图片为独立竖版漫画，上下分镜、少字大字，禁止把横版整图直接缩小后当作手机适配完成。

首页简短导读；第二个阅读入口列重点目录，简讯目录紧邻简讯。提供整期目录、逐篇书签、文内跳转和原文链接。页码和书签必须读取实际PDF分页后生成，不按模板估算。正文自然续页；每则简讯从新页开始，本期23则各一页，但不以缩字或删内容强求以后全部一页。

简讯先说明具体问题和新变化，再解释做法、数字和必要状态；可分两三个自然段，不强套“背景—机制—意义”栏目。保留机构、日期和原文链接。摘要、术语、统计口径及状态应能通过大字正文理解，不能要求读者放大漫画查找关键条件。

## 渲染输入与执行

先完成当期核准的阅读HTML；手机渲染不抓取、不改archive/state/知识库，也不触发邮件。

- `--source`：当期核准阅读HTML，含 `.topic-primary`、`.report-highlights` 和 `.short-brief`。
- `--briefs`：当期简讯编选JSON，按原顺序列 `index`、`title`、`paragraphs`、`url`；编号连续，原文URL必须与源HTML逐条相等。
- `--comics`：本期竖版漫画目录，文件为 `01-手机漫画.jpg` 等，每幅先实际查看和核准。
- `--edition-json`：手机首页编选，字段见本期 `手机首页编选.json`。日期、窗口、机构数、导读和导航标题全部用当期数据，不能复制旧期事实。
- `--output-dir`：独立手机阅读版目录，保留桌面文件。

使用已核验且具备BeautifulSoup、PyMuPDF和浏览器渲染依赖的本机Python，调用 `scripts/render_mobile_weekly.py`，显式传同一业务日期。依赖缺失时停止渲染，不自行安装绕过自动化前置门。

渲染器检查正文段落、摘要、标题、元信息、列表及表格文字完整性，按实际目标页生成书签，并将浏览器命名跳转转换为显式PDF页内跳转以改善移动阅读器兼容性。输出核验JSON中的 `visual_review` 初始为pending，须在实际页面检查后更新。

## 实际验收

每期把PDF按约390像素页宽渲染查看：正文不必横移；漫画标题、标签和关键口径能读；无裁切、重叠、孤立标题或空白尾页。检查全部页面和原图，特别检查长标题、来源跨行、长段续页、每篇结尾及目录链接。结构检查不替代视觉检查。页数随内容增长，不为压页数缩小字号。

本期2026-10-18手机阅读版为61页：6重点、23简讯、6竖版漫画；181个文字块完整，31个书签，157个有效内部链接。详见 `docs/run_receipts/2026-10-18_mobile_revision.md`。这些数字仅是本期验收结果，不能作为下期固定值。
