# 每周研究关注：从关键词到问题（2026-09-23）

本表依据既有独立研究项目、反复研究的问题和近期明确要求提炼，不是全库精确词频统计。同一项目的版本、译本、脚本、图示和归档副本不重复计权。项目卡中的重复或混入条目不作为独立证据；行政、凭据及工具目录不推断为研究兴趣。

## 三项明确重点

| 主题 | 希望持续读到的内容 | 检索入口举例 |
|---|---|---|
| 企业基础研究 | 企业为何投入或放弃；需求如何转化为持续投入；组织、合作、资助与评价如何影响长期能力；企业遇到的真实困难 | corporate basic research、corporate science、corporate research laboratories、企业基础研究 |
| AI4S与科学研究变革 | 科学问题和发现方式如何改变；自动化实验闭环；科学模型、数据、设施、算力及科研组织如何共同演化 | AI4S、AI for Science、scientific foundation models、self-driving labs、AI-ready data |
| 区块链与可信协作 | 协议、验证和治理机制；零知识证明；科学与产业协作；数字资产、支付、智能体和数据空间中的真实应用与障碍 | blockchain、distributed ledger、zero-knowledge proof、DeSci、tokenization、stablecoin |

这三项来自用户明确指定，并分别有企业基础研究、AI时代重大科学设施、区块链研究等项目支持。区块链不缩成金融行情；AI4S不等同全部AI报告；企业基础研究不等同全部企业研发。

## 六组持续研究的问题

| 主题 | 值得继续追踪的问题 | 项目依据类别 |
|---|---|---|
| 科研资助、科学慈善与长期资本 | 政府、企业、基金会和投资机构怎样支持高风险研究、科学家创业和企业成长？资助与投资设计怎样改变创新选择？ | 科学慈善与社会化基金、联合基金资助效能、科创策源投资等独立研究 |
| 科产融合、成果转化与创新采用 | 发现如何进入生产与市场？概念验证、中试、客户验证、采购和应用场景解决了什么问题？采用为什么停滞？ | 实验室科产融合、科产融合调研、创新型采购、区域创新生态研究 |
| 科研组织、重大计划与设施平台 | 重大任务、公共机构、企业和团队怎样分工协作、承担风险和评价？设施、数据与服务能否真正被用户使用？ | 重大科技计划、重大科学设施开放共享、实验室与区域平台研究 |
| 人才、团队与企业创新能力 | 技术瓶颈需要怎样的团队、技能、协作和吸收能力？招聘、流动、激励与组织学习有什么困难？ | 人才招引、前沿技术与人才图谱等研究；不重复计入过程文件 |
| 企业国际化与区域创新网络 | 市场、技术、人才、合作伙伴和服务如何跨境连接？区域生态及国际环境怎样影响企业机会、成本与能力？ | 科技企业国际化、中小科技企业出海、跨区域创新机制及区域规划研究 |
| 前沿交叉研究与科学路线 | 新工具、新研究对象和学科交叉改变了哪些研究问题？怎样区分可信早期信号、分歧和概念热潮？ | 前沿交叉研究、科学路线与重大计划组织研究 |

具身智能、硅光、二维及超宽禁带半导体等保留为阶段性赛道线索，不自动与三项明确重点同权。企业进入退出、融资约束、生产率、创新失败、管理、需求、供应链及其他新问题，只要有独立研究价值，仍可进入周报。

## 怎样影响每周任务

1. 先读本表与 `config/research_interests.yaml`，再做广泛发现；对三项明确重点主动使用中英文同义词及问题词补查。某周没有合格新研究属于正常结果，记录检查过的来源、检索方向及无新增原因，不补旧文凑数。
2. 程序在画像过滤前，把任一来源标题或公开摘要命中关注词的候选放入同一份 `*_source_health_editorial_review.csv`，同时保留经济与企业来源全部窗口内/待核日期候选。表中记录关注主题、检索词、原始优先级与复核理由；同一候选命中多个主题仍只占一行。
3. 命中只是阅读线索，不证明相关性、原创性或研究质量，不改变原始评分和P0/P1。模型继续按研究问题做语义复核；未命中也不能据此排除有价值的研究。全文书目或机构导航中的关键词不作主题证据。
4. 对采纳材料说明它推进了什么认识：新机制、测量方式、异常发现、案例细节、制度设计、路线分歧或现实困扰均可。优先级由内容与证据决定，不要求逐个对应本表、不设篇数配额。
5. 有价值的内容展开为可独立阅读的“精华选编”，可包含完整案例、方法说明、图表和对比，不限于摘要或论据。漫画与摘要提供入口，深读内容可接排，也可在后页展开。每月根据实际有用材料和漏检记录有限调整关注词。
