# 每周研究监测：经济、企业创新与执行质量（2026-09-23）

本规则用于 automation-4；与旧检索策略冲突时，按本文件执行。调度时间、模型、通知、邮件对象及既有发布授权仍由自动化配置和本机运行文档管理。本文件不授权临时补发邮件或历史回填。

## 研究判断

研究视野覆盖科技、经济与社会转型。企业是创新主体：既观察研发和技术，也观察企业面对的问题、约束、选择与行为。需求变化、成本、人才技能、组织管理、竞争与市场进入、供应链、政策不确定性、资本配置、区域和国际环境，都可能有研究价值。

这些方向是开放的检索提示，不是封闭目录，不设主题配额，不要求材料逐项对应，也不要求标题出现科技、创新、AI或金融。判断重心是报告提出了什么值得理解的问题、有什么可靠证据、对企业创新行为或创新环境有什么解释价值。宏观、产业、公共政策研究同样可纳入，不能将周报缩成企业融资或进入退出专报。涉及经济背景时，区分原报告结论和研究者解释，不编造原文没有的技术关联。

每轮先广泛发现，再逐篇判断。关键词分数用于辅助发现和排序，不能成为未命中材料消失的理由：
- 先读取 [研究关注说明](research_attention_2026-09.md)、[自动补词与复查规则](keyword_evolution.md) 和 config/research_interests.yaml。企业基础研究、AI4S、区块链是已明确的起点，既有九组主题均不构成封闭目录。每周从核准原文、未命中材料和真实研究问题自动增补同义词、问题及探索议题，更新配置并留痕，无需逐词请求批准；不按文件数量或词频推定兴趣，不设新增配额。对重点无合格新品也记录检查路径，不补旧文。
- 读取健康审计生成的 *_source_health_editorial_review.csv；该表保留所有来源的窗口内候选和待核日期候选，包括P2/P3、画像及关注词完全未命中项。先浏览全部标题/公开摘要，再按实质价值精读，保留不依赖既有词表的开放发现。关注词只作线索，不累加评分或自动升P0/P1；未命中仍可语义采纳。
- 逐条核实首次发布日期、原文、方法或数据、研究对象与解释价值，记录采纳/排除/待证及原文页码或段落。未读正文不得伪装成完整研究卡。
- 若低分材料经过原文复核值得重点采用，在当期决策记录中保留原始分数、语义采纳理由、证据定位与复核优先级，再用现有归档、状态与知识库接口受控写入并做全链路一致性核验。不得改写原文摘要、堆关键词或降低全局阈值制造命中。
- 仅有摘要且无法取得足够原文的材料列入线索，不进入全文已读统计或漫画深度解读。

## 来源池及发现方式

默认batch<=1由37个配置源扩至53个，新增16个：
- 经济与企业研究：ZEW、KfW Research、EIB Research、ifo、DIW、NBER、CEPR、BIS。
- 企业行为与咨询研究：MGI、BCG、Deloitte Insights、PwC、Bain。
- 创新投资与生态数据：KPMG Venture Pulse、PitchBook–NVCA Venture Monitor、Dealroom。
- 同时激活既有OECD STI的中小企业与创业系列，以及Bruegel、CEPS、ECIPE的企业、经济、竞争和贸易研究。

每周检查上述来源，不要求每周都有新报告。季刊、年刊无新品应记录为正常零新增。Startup Genome、EIF、IWH，以及有价值的IMF、世界银行、RIETI、Kiel等研究作为按问题追加发现的来源，不能因不在固定名单就拒绝；也不得无限扩源替代本期交付。

官方科技创新机构的重要发布亦可补充，按[官方科研机构可选补充规则](official_research_optional.md)执行。包括UKRI等机构的重大计划、研究报告、资助或评审机制和组织模式创新，不限中央政府战略文件。以具体变化、研究价值和官方原文为依据，不因是资助通知就排除，也不因官方身份自动升级。此项无固定篇数或每期必选要求；无合格内容不占位、不作为失败。UKRI官方目录是明确补查入口，其余同类来源按问题有限拓展，不改变53个默认配置源的统计口径。

新增来源采用“程序发现 + 官方补查”的混合方式。2026-09-23实测已确认部分网站对直接请求返回403/406、超时，KfW等以PDF为主，咨询官网还可能混入导航。此清单表示纳入监测，不能称全部稳定自动抓取。逐源对照配置及官方入口，记录：
1. 正常检查且无本期新品；
2. 入口/解析失败；
3. 日期或正文待核；
4. 有新品但不符合研究质量；
5. 有合格新增。
零候选不能直接等同于无发布。对入口失败、导航占位、PDF直链、动态目录或已知系列未出现的来源，用官方域名搜索、可访问官网/浏览器及公开PDF补查；不绕过付费墙或自动填表注册。补查同样严格遵循当期窗口。各来源的入口见config/institutions及来源梳理说明。

## 证据与比较边界

- 首次出版日、新闻发布日、发现日、数据覆盖期分别记录；看到旧报告不等于本周发布，网页更新时间、页脚年份、搜索抓取日不作发表日。月份不精确时不得擅自填当月1日进入周报。
- 官方计划同时区分发布、申请开放/截止、实施及批准状态。计划设计和机构主张不等于实际成效；重大性不限金额大小，创新性须说明具体设计或变化，不能仅据名称和宣传判断。指南、新闻稿与计划正文按同一事项去重。
- 版本、译本、全球版与地区版、报告与新闻稿、联合发布方按同一作品去重；稳定系列页用于发现，实际归档定位到当期作品。不能把同一稳定URL的页面更新当新报告自动入库。
- ZEW Unternehmensschließungen是企业关闭/退出，不能等同破产；创投IPO/并购退出另有口径。2026版还涉及时间序列修订，不得跨版直接拼同比。
- KPMG Venture Pulse与NVCA Venture Monitor常共同使用PitchBook数据，不能当两套独立数据互证；记录数据提供方、地域、样本、统计期、估计及方法变化。
- 商业研究不因商业身份自动降为候补，也不因品牌知名免检。区分数据、调查意见、案例、预测/情景和咨询解释，相关关系不写成因果。
- NBER、CEPR、BIS等署名论文是作者观点，不自动表述为机构正式立场。
- metadata_summary_only来源仅落盘公开短摘要、元数据、链接及自有中文分析，不保存限制范围内正文。无法核实正文时明确证据限度。

## 首页编辑导读与开篇导航

整期首页采用“一页编辑导读”，帮助读者判断本期值得读什么、为什么值得读、从哪里进入。参考已确认的2026-09-23首页样张：紧凑刊头和日期窗口，收录数量、重点数量及本期收录机构数合并为一行；机构数指实际收录机构，不得冒充已检查来源数。取消“封面、必读、议题速览、目录”固定各占一页的开场。

首页内容由本期已核准材料编选，先完成各篇精华再编辑首页，不从标签计数拼“本周态势”。按内容安排以下部分：
- 本期阅读主线：简洁说明值得共同阅读或分别追问的问题。跨报告综合判断须有明确依据，区分共同发现、相互分歧与编辑提出的问题；依据不足就用阅读线索，不制造机构共识或趋势变化。
- 重要发现：通常选择两三处有辨识度的反差、案例、数据或方法，说明具体发现和继续阅读的价值，定位到当期篇章及原文。材料不足时按实际呈现，不凑数量。多个发现不能只是漫画标题或原摘要换词。
- 与持续研究的连接：按本期内容选择企业基础研究、AI4S、区块链或其他真实关联的问题。没有实质关联时不硬贴标签，不要求每期三项都出现。
- 精简导航：将必读、议题速览和目录合并为紧凑阅读入口，指向对应精华篇章。完整目录可依篇幅放在正文末尾自然续排，首页保留对应锚链接；不为每类导航固定占一页，不把重复导航推成另一张半空前页；同一判断不在多处重复展示。

有特别值得呈现的原始图表、制度比较或方法示意时，可替换部分发现模块成为首页重点。数值写清年份、单位、分母及适用范围；原图/重制图表保留来源和使用依据。首页以信息价值决定选材，不为填白添加装饰大图、重复摘要或未经核实的观点。

首页的编辑文字单独保存到当期编选文件，随当期资料受版本控制，标明业务日期及所依据条目的链接/原文位置。渲染只能排版和链接这些已撰写内容，不把程序计数称作实质编辑判断。初步渲染缺少编选时可呈现真实收录概况和条目导览，正式投递前须完成首页编辑复核；没有重点材料的周次按实际报告零新增或线索。

具体输入保存为 `briefs/weekly/<年份>/<D>_editorial.json`；字段、图表输入和核验要求见 [首页编选输入说明](weekly_editorial_input.md)。文件日期及引用篇章与本期核准材料一致；修改编选后重新渲染，避免内容已经更新而投递旧首页。

渲染后目视检查整期第1页及其后导航：刊头不过大，正文可读，来源可辨，信息自然覆盖页面，没有大片异常留白、重复开篇、截文或溢出。首页过长时优先精炼入口文字或将次要导航移到后页，不能靠缩小字体、裁掉内容解决。导航使用实际篇章锚点；只有核验渲染后真实页码才标页码，禁止继续按每篇两页估算。

## 漫画导读与精华选编

先精读原报告，选出值得完整呈现的内容并完成中文精华选编，再提炼摘要和漫画。周报的深读部分不是给漫画补几条“论证与依据”，而是让读者读到原报告最有价值的内容：有辨识度的发现、完整案例、制度安排、方法步骤、概念区分、数据图表、比较、分歧和适用条件。按原报告特点选择，不强制每篇一套栏目；不从漫画提示词反向扩写，不靠增加套话凑篇幅。

深读部分可展开多个小节和多页，不以“摘要＋论据”代替实质阅读。一个关键案例可以完整讲清背景、设计、实施、结果与限制；方法可以保留读者理解和使用所必需的步骤；图表应连同标题、坐标、单位、图例、统计期、样本、注释和来源一起呈现，并解释值得注意的关系。无需把所有图表重新塞入漫画。

所选内容可以摘编为完整的中文章节或专题文章，并明确“选编范围”，不声称报告全译或全文已读。具备许可、公共领域或用户提供的内容，可按适用范围保留完整所选章节及原始图表并注明出处；其他材料采用有实质细节的自撰编译、必要短引及基于可使用数据的准确重制图表，保留原文链接。原文摘录、中文翻译、自撰整理、编辑分析和重制图表应区分；许可或阅读范围不明时不得冒称授权/全文。metadata_summary_only来源的正文落盘限制继续有效。

“全文呈现”是把选中的精华文章或章节完整交给读者，不在渲染时截成前4句、每句240字或省略结尾，也不默认复制整份外部报告。不能满足于“报告讨论了X、强调了Y、建议加强Z”。有可靠数字时写清分母、时期、样本和比较对象，没有数字不造数字。若漫画已表达主判断，选编继续提供具体知识、案例过程、方法或反例，不能逐句复读。

版面允许“漫画＋简短摘要/导读”作为入口，后页为精华选编，也允许自然接排。材料较长或包含重要图表时，可显式让选编另起一页；不要把所有报告机械强拆两页，也不要把所有深读内容硬塞在图片下面。漫画页下方有可用空间时可放有信息量的导读、阅读提示或简洁的关键数据，不用套话填空。章节跨页随内容长度安排，图表及说明尽量相邻；视觉验收后再决定分页。

编辑落盘使用 ArticleCandidate.highlights_markdown，或研究卡中独立的 `## 精华选编`，以 Markdown 保存连续正文、小标题、表格、来源链接及工作区内图表路径；不要塞入“核心观点”字段后依赖旧拆句器。短摘要仍放“核心观点”，有精华时按完整摘要导读呈现。highlights_title 可命名所选专题，highlights_start_new_page 控制是否另起页；默认接排。highlights_usage=editorial 表示自撰整理；原文摘录或翻译型选编使用 licensed_excerpt，并在 highlights_permission_verified / highlights_permission_note 记录已核明的许可、公共领域或用户提供材料等依据。明确已有依据即可，不另设重复审批；无依据采用自撰整理。原文受限来源的自有分析不应被静默删除。

每期逐篇做原文—研究卡/精华选编—摘要与漫画—阅读版对照，记录“选了哪部分、为什么值得完整读、比漫画增加了什么”和重要内容的页段定位。必读材料若只有几条泛化摘要，应返回原文补足有价值的内容；原文本身不支持深读则降为简讯/线索，不伪装精华全文。按报告对象检查方法与证据，优先复核必读及异常稿。字数、句数和有无表格只检查形式，不能自动声称亮点或可读性达标。

特别防止作者/机构混同、建议被改写成事实，以及参考文献题名被误当报告结论。仅在正文论证有直接依据时保留中国/上海参考；文末参考文献出现China、上海或某篇涉华论文，不足以证明该报告提供了涉华技术能力或地方政策建议。

图片验收除数量和引用外，必须逐张对照原文和核准正文核查国家/机构/对象名称、数字、比较关系、方向与条件；不能把条件性判断画成普遍结论，也不能任由生图增加原文未列对象。发现错误修正图文后再验收，不能因为图片数量通过就投递。

## 每期执行及验收

1. 固定北京时间本轮业务日期D；窗口为[D-6,D]，含两端恰7个日期。全流程显式传同一个日期，不因跨午夜或重试漂移。周脚本必须传 -Date 和已验证的 -Python 绝对路径。
2. 在隔离工作树核对干净状态、目标远程版本和依赖，运行测试。不得修改已有未提交的OneDrive主副本。
3. 运行只读健康审计，检查全部53个配置源均有行；“近7日可入选”必须已详情成功。同步读取待复核队列并逐源官方补查。审计不写archive/state/知识库。
4. 每机构候选上限由Limit和run_limit决定，先截断后核日期可能漏掉新品；对列表前部导航、旧条目占位或本周低覆盖来源定向补查。禁止用扩大日期窗口解决。
5. 运行当期抓取，逐条复核。周频详情失败不写“已处理”；历史失败且无归档的URL允许重试。已经成功归档的同一作品不重复写入。
6. 检查最大单源>30%、前二>50%、或至少6条重点却不足6家机构的集中度提醒；除按原规则补查科技和官方战略外，也检查经济与企业研究是否缺失，以及是否由访问/画像/候选截断造成。不通过凑数、硬配额或旧材料填充消除警报。
7. 研究卡及精华选编保留值得完整阅读的发现、案例、方法、图表或制度细节，篇幅随实质内容决定。摘要和漫画只作为阅读入口。机构/作者建议、原文摘译、自撰整理与研究者分析分开；没有中国/上海依据时不强加关联。
8. 漫画沿用每条P0/P1真实原生图要求。先完成并核准研究卡，再生成图片；有效中间产物允许同一期复用，避免429后重抓/重绘已完成材料。生成或渲染失败保留阶段结果并报告，不能宣称整期完成。
9. PDF采用首页编辑导读加分层阅读：整期首页按已确认规则编选主线、重要发现、研究连接和精简导航，取消固定四页开场；新报告开始换页，漫画和摘要作导读，精华选编可接排或另起页，并完整展开到后续页。不得机械强拆两页，不拉伸或裁切原图，不靠删正文、压小字号消除空白。渲染后检查整期首页与导航、漫画页留白、图表及说明相邻、长文跨页、选编全文完整、全部图像引用和PDF生产器。漫画与首页/选编图表分别计数，其他图表不能冒充真实原生漫画。
10. archive、state、知识库索引、资料索引、Markdown/HTML/PDF、漫画一致后，按原受控流程提交推送。OneDrive仅在干净时快进；脏副本保持原状并标记同步阻断。
