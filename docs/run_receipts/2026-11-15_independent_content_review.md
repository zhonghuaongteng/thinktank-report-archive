## 发现与处置

1. **GPEx责任方向歧义，已修。** 初稿“与UKRI承担合同责任”容易被理解为双方共同承担。原报告第4.1.1节（PDF物理30页）规定牵头机构负责合同、交付、报告和协调。已观察JSON改为“向UKRI承担履约责任”。应同步使用修改后的输入，不回退到旧MD或旧合并稿。
2. **CSIS投资开放方向歧义，已修。** 84.6%所指是美欧开放接受中国投资，不是中国开放接受美欧投资。原稿语序不清，JSON已改为“应优先由美欧扩大对中国投资者的开放”，第三次读取确认方向及语序均已修正；最终合并文本应使用此版本。
3. **6G首版图增加未核准清单，已用修订图解决。** 首版在需求单额外列出交通、医疗等应用，既不来自已核准漫画文案，也未清楚表达报告优先建议的空中目标感知。原文虽讨论沉浸体验等备选能力，但并未让该图的整套清单成为本篇结论。`6g_corrected.png`已删除额外清单，改为空中目标感知，并减少自行扩写的气泡说明。修订图与选编一致；正式版本应采用修订图，首版不通过。
4. **摘要限额仍需对最终合并版留痕，不能用本记录代替。** 检查时长版CEPS/CSIS已被短稿替换；没有发现当前稿把本地下载声明为可解除网页工具的单源限额。单源预算应同时覆盖摘要、正文、重复导读及图中文字，网页和PDF是同一作品时不能重复获得额度。CNRS的2025年背景材料另有明确出处，可按不同作品分别计算，但不能借背景来源额度扩写当期文章。当前未提供可复核的逐源合并预算表，故本记录不宣布此项最终通过，也不以汉字数直接冒充英文词数。
