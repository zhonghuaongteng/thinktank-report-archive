## 日本讨论产业竞争力与研究力核心大学制度

日本文部科学省与经济产业省11月16日提交的讨论稿，把大学改革和企业长期投入放在同一项制度中设计。稿件引用2024年度大学产学合作调查：约八成共同研究项目的单项收入不超过300万日元。两部门希望推动企业与大学管理层共同承诺的大型长期项目。

拟议遴选同时考察大学既有实绩、未来构想和具体承诺。企业需明确人员与资金投入，大学需把战略落实为部门行动计划，并配备产业分析、知识产权和研究支持人员。材料建议由专业人士及主管部门约每五年判断是否继续认定与支持；研究结果指标应避免诱发短期成果冲动，组织改革则须检查实际进度。认定责任由单所大学承担，同时允许跨校合作和交叉聘任。

## EIC基金受资助企业调查

欧洲创新理事会11月17日公布的调查，反映企业如何评价公共股权投资。调查于2026年3月启动，获得182份可用于分析的企业回答，约占当时752家基金企业总体的24%；不同问题由处在不同投资阶段的企业回答。

在回答最近一轮融资问题的78家企业中，64.1%认为EIC参与不可或缺，16.7%认为有帮助，14.1%认为未产生影响。另一道多选题同样获得78份回答，其中57家认为支持提高了投资者对自己的关注和认可，44家认为提高了公共机构与创新网络的认可。

企业希望基金增强后续投资能力、减少行政手续，并更清楚地解释投资决定。调查还分别记录了补助与股权配合、尽职调查和投资者对接体验。这些意见来自已进入EIC基金流程的企业，具体比例随回答问题及所处阶段而变化。
