# 日本经济产业研究所（RIETI）轨迹卡

## 机构角色

- RIETI是日本经济产业省体系内的政策研究机构，其讨论论文适合补充科学、技术与创新如何进入企业行为、生产率、产业政策和成果转化的机制证据。
- 讨论论文与政策讨论论文的观点按作者归因，不自动视为RIETI或日本政府的正式立场。
- 本地资料采用“英日文题名级轻量目录—每年一个科技创新机制节点—有上限的中国科技创新机制补充”结构。

## 近十年议程轨迹

| 时间 | 精选节点 | 可复用机制 |
| --- | --- | --- |
| 2016—2017 | 公共科研机构、产业科学密集度测量 | 科研组织通过技术服务、知识扩散和数据连接进入产业创新系统 |
| 2018—2019 | 深圳区域创新体系、日本地方公共技术转移组织 | 技术、风险资本、人力资本与公共转移机构共同塑造区域创新能力 |
| 2020—2021 | 开放科研数据、大学知识与科研成果商业化 | 科学开放与成果利用之间存在激励和制度协同问题 |
| 2022—2023 | 政府研发支出推动技术融合、科学成果商业化模式 | 公共研发投入的效应取决于技术组合与转移机制 |
| 2024—2026 | 企业基础研究、企业科学家、公共技术转移组织 | 企业内部科学能力与公共转移网络共同连接论文、专利、设计和商业化 |

## 中国维度

- 2018年深圳材料提供区域创新系统的直接案例，强调技术能力、创业融资和人力资本的组合。
- 2020年以专利文本比较百度与Google的技术竞争力，2024年以专利和网页内容比较中日美创新过程。
- 新增材料补入ICT与中国生产率、进口竞争下企业创新、产业补贴与企业创新、新型举国科技创新体制、机器人进口与企业绩效、生成式AI监管与创新平衡，形成从创新投入、组织方式到技术吸收和制度约束的机制链。
- 2024年标准必要专利材料进一步连接政府许可干预、智能手机厂商成本、产品价格与系统级芯片市场，补足知识产权制度影响技术商业化的量化证据。
- 对华贸易、技术脱钩、出口限制和经济安全材料只作背景目录，不进入本批精选全文。

## 本地调用

- `194_RIETI科技创新与中国近十年轻量总目录.csv`：2016—2026年英日文讨论论文与政策讨论论文224项。
- `196_RIETI科学技术创新机制与中国比较跨期精选全文台账.csv`：19份官方PDF，606页、1,155,837个规范化文本字符，其中9份为中国科技创新直接材料。
- `214_跨机构中国科技创新机制定点增补台账.csv`：新增1份中国智能手机和系统级芯片标准必要专利材料；RIETI本地全文合计20份。
- `220_科研人才知识转移与创新商业化定点增补台账.csv`：补入全球科研合作网络与企业基础研究—产学合作2份机制论文；RIETI本地全文合计22份。
- `03_证据底稿/文本/C-JP-RIETI-*.txt`与`03_证据底稿/切片/C-JP-RIETI-*.md`：用于机制检索、全文复核和后续页码定位。

## 边界

- 轻量目录只支持议题方向和产出结构判断；具体主张、因果关系和政策含义须回查作者署名的全文。
- 目录筛选要求出现科学、研发、技术、创新、专利、科研组织、科技人才或数字技术信号。一般产业、生产率、贸易和供应链题名不因涉华而自动纳入。
- 论文样本多为实证研究，适合提供机制证据；机构战略转向仍需与RIETI项目设置、年度计划或组织层材料交叉验证。
