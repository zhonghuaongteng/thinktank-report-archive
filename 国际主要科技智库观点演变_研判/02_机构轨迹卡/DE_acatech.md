# 德国国家工程科学院（acatech）轨迹卡

## 机构角色

- acatech连接工程科学、产业实践与政策咨询，适合观察德国如何把技术研发、工程方法、企业组织和产业转化纳入创新体系。
- 本地目录覆盖官方WordPress出版接口中的2016—2026年全部正式出版物，完整保留题名、日期、文类、主题、摘要、落地页和PDF入口。
- 全文层只选择能够解释科学与工程能力、技术路线、创新组织或成果转化机制的跨期材料；合作出版物按共同机构归因。

## 近十年议程轨迹

| 时间 | 精选节点 | 可复用机制 |
| --- | --- | --- |
| 2016—2017 | 工业4.0工程方法、国际比较与成熟度模型 | 技术升级由设备数字化扩展为工程流程、组织能力、技能和企业转型路线 |
| 2018—2019 | 突破性创新、工业4.0前竞争性研发议题 | 研发组织、资助工具与技术转化速度成为创新体系的关键变量 |
| 2020—2021 | 第二代量子技术、德国工程科学与产业能力 | 前沿技术潜力进一步连接工程学科、人才、研究组织和产业应用 |
| 2022—2024 | 先进系统工程、生物技术转化、聚变创新生态 | 政策重心转向复杂系统能力及从科学发现到产业生态的全链条组织 |
| 2025—2026 | 区域AI能力、工业4.0支持循环价值创造 | 技术创新通过区域能力测度、企业采用和新型价值链进入规模化应用 |

## 中国维度

- 2016年《全球语境中的工业4.0》设有中国比较，涉及中国制造业数字化、自动化技术需求、创新中心合作和中德技术标准协作，是直接中国科技创新材料。
- 12份精选全文中7份出现China、Chinese或Volksrepublik词形，多数属于国际比较或背景提及；只有经正文核验的实质段落才能作为中国证据。
- 对华竞争、安全、技术主权和供应链题名不因China或安全词形自动进入全文层。

## 边界

- 轻量目录保留官方出版结构，题名和摘要可用于观察议题分布，不能直接替代机构观点编码。
