# 报告观点编码手册（试编码版）

## 证据等级

- L3：机构正式立场。旗舰/委员会/年度成果，且官网明确以机构名义发布。
- L2：项目立场。同一项目、负责人或连续系列至少两次持续表达。
- L1：作者立场。单篇署名报告、评论或博客；不得直接上升为机构观点。

## 核心字段

| 字段 | 操作定义 | 允许值或记录方式 |
|---|---|---|
| 问题诊断 | 报告认为政策失灵或风险产生的首要原因 | 原文转述+页码 |
| 因果模型 | 从问题到结果的关键传导链 | A→B→C |
| 首要目标 | 在冲突目标中被明确置于首位者 | 增长、能力、安全、韧性、转型、权利等 |
| 国家角色 | 政府介入的范围与深度 | 规则、投入、协调、定向、生产能力、管制 |
| 市场角色 | 市场被视为发现、扩散或配置机制的程度 | 主导、互补、受约束、需纠偏 |
| 国际合作 | 对开放、互赖、联盟、风险管控的定位 | 开放、条件开放、盟友化、去风险、脱钩 |
| 主要工具 | 资源配置与约束手段 | 税收、补助、采购、任务、标准、审查、管制等 |
| 变化类型 | 与同机构同题前期报告比较 | A—H |

## 变化类型

- A：核心理论或因果模型变化。
- B：政策目标重新排序。
- C：政策工具或国家角色变化。
- D：国际合作或风险判断变化。
- E：旧观点由边缘走向主流。
- F：新议题纳入原有框架。
- G：术语变化、实质稳定。
- H：短期事件响应。

“战略转向”只用于A—D；E为主流化，F为议程扩展。

## 报告卡最低字段

报告ID、机构/项目、国家或地区、报告题名、日期、作者、报告类型、原文/PDF、页数、机构观点等级、示踪问题、问题诊断、因果链、首要目标、国家/市场/国际合作角色、主要工具、关键引文页码、最强反证、适用边界、与前期报告的延续和变化、变化类型、置信度。

## 试编码与冻结

首批使用OECD STI Outlook、ITIF科技竞争系列、CSIS国家技术战略系列。完成至少12份报告的试编码后仅允许修订一次字段与锚定示例，随后冻结。正式样本完成后随机抽取10%独立重编码；核心字段一致率低于80%时重编受影响字段。
